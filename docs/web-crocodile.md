# Крокодил: новая игра (веб) — для переноса в React Native

> Дата: 2026-10-18. Изменения сделаны **только в вебе** (`src/`). В `mobile-app/` ничего не менялось — этот файл описывает, что и куда переносить.

## Правила игры

- Игроки делятся на команды (2–4, как в Alias: `SetupPhase` с чипами игроков, тап переносит игрока в следующую команду). Минимум 4 игрока, минимум 2 в команде.
- **В начале игры выбирается цель** — до скольких очков играем: `TARGET_SCORES = [10, 15, 20, 30]`, по умолчанию 15. Хранится в сессии (`targetScore`).
- Команды ходят по кругу; объясняющий внутри команды меняется по очереди (`team.players[turnsPlayed % n]`).
- В каждом раунде объясняющему показывают **3 слова — по одному каждой сложности**:

  | Сложность | Очки | Время |
  | --------- | ---- | ----- |
  | easy      | 1    | 60 с  |
  | medium    | 2    | 90 с  |
  | hard      | 3    | 120 с |

  (`CROCODILE_LEVELS` в `constants.ts`.)
- **Замена слов:** кнопка «Заменить все слова (−1)» меняет все три слова разом и сразу снимает 1 очко у текущей команды. Счёт **может уйти в минус** (не ограничивается нулём). Заменять можно сколько угодно раз.
- **Время идёт только после выбора слова** (тап по карточке) — запускается таймер на время выбранной сложности.
- Во время раунда две кнопки: «Угадали» → команда получает очки слова; «Сдаёмся» или истёкшее время → 0 очков. Затем экран итога раунда и «Продолжить».
- Победа: команда, у которой по окончании её раунда счёт `>= targetScore`. Экран победы показывает таблицу счёта всех команд.

## Фазы

`CrocodilePhase`: `setup → start → choose_word → playing → round_end → game_over` (const-объект, значения строк как в вебе — нужны для восстановления сессий).

Поля сессии (`usePersistedState`): `teams`, `currentTeamIdx`, `phase`, `targetScore`, `wordOptions` (3 предложенных слова), `chosen` (выбранное слово + сложность), `guessed`, `timedOut`, `timeLeft` (через `usePersistedTimer`).

## Слова

- `src/games/CrocodileGame/content.ts` — `CROCODILE_WORDS: Record<Difficulty, string[]>`. **Не менее 200 слов в каждой сложности** (сейчас easy ≈ 210, medium ≈ 226, hard 200); между сложностями слова не повторяются. Содержимое — русский игровой контент, **не переводится** (файл копируется 1:1).
- `model/crocodileContent.ts` — `drawWordOptions()`: для каждой сложности `drawFromPool(poolGameId(GameKey.Crocodile, difficulty), pool)`.
- **У каждой сложности свой used-пул**: ключ `crocodile_easy` / `crocodile_medium` / `crocodile_hard` (`poolGameId` в `constants.ts`). Причина: `availableFromPool` при исчерпании сбрасывает used-список всего `gameId` — с общим ключом исчерпание лёгких слов обнулило бы историю средних и сложных. Показанное слово помечается использованным сразу (даже если его не выбрали или заменили) и не повторяется, пока в этой сложности есть другие; когда все показаны — пул сложности сбрасывается и слова снова доступны.
- Кастомных слов и счётчика остатка (`contentService.WORD_POOLS`) нет — игра без общей настройки сложности (`hasDifficulty: false` в реестре).

## Звуки

В `feedbackService.playSound` добавлены два новых типа (Web Audio, осциллятор):

- `tick` — тихий сухой «тик» (square 1000 Гц, 0.04 с, gain 0.04);
- `tickUrgent` — тик последних `URGENT_SECONDS = 10` секунд (square 1500 Гц, 0.06 с, gain 0.07).

Тик играет в `useEffect([phase, timeLeft])` один раз за каждое значение `timeLeft`, пока `phase === Playing && timeLeft > 0`. Сигнал окончания времени — существующий `playSound('timeout')` + `vibrate(VIBRATE.timeout)` в `onTimeUp`. Также используются `start` (выбор слова), `success` («Угадали»), `error` («Сдаёмся», замена слов), `win`.

## Заметки по RN

- **Тик-звук.** В вебе звук синтезируется осциллятором — в RN этого нет. Нужны два коротких аудиофайла (`tick`, `tickUrgent`, ~40–60 мс) и проигрывание через `expo-audio` (или тот механизм, что уже стоит за `feedbackService` в RN). Файлы предзагружать заранее, иначе первый тик запаздывает. Звук должен учитывать настройку `sounds`; на iOS убедиться, что тик не прерывает музыку/не ломает режим беззвучия по желанию.
- **Таймер в фоне.** Если приложение уходит в фон посреди раунда, `setInterval` встаёт — при возврате стоит пересчитывать `timeLeft` по метке времени (в вебе так не делается, но на мобильных это заметнее). Минимум — не ронять сессию.
- **Секретность слов.** Экран выбора слова виден только объясняющему — текст-подсказка `chooseHint` обязателен. Рекомендуется не показывать слова повторно после смены фазы (`wordOptions` остаются в сессии только для восстановления после перезагрузки).
- **Длинные слова** (`Дарёному коню в зубы не смотрят`, `Кругосветное путешествие`) — слово на карточке выбора, на экране раунда и на итоге через `FitText`-аналог (W-01 в `web-ux-fixes.md`). Карточки выбора — `Pressable` минимум 96 pt высотой.
- **Кнопки раунда** внизу экрана: отступ с учётом safe-area (`pb-[calc(2rem+env(safe-area-inset-bottom))]` в вебе → `useSafeAreaInsets().bottom + 32` в RN).
- **Moti + `AnimatePresence exitBeforeEnter`** (см. `gotchas.md`): на каждом `MotiView` с `exit` явно ставить `transition={{ type: 'timing', duration: 200 }}`.
- Круг таймера — `react-native-svg` (`strokeDashoffset` через `useAnimatedProps`), цвет красный при `timeLeft <= URGENT_SECONDS`.

## Проверка после переноса

- 4 игрока → 2 команды; 8+ → можно 4. Цель по умолчанию 15, выбор сохраняется после перезагрузки.
- Экран выбора: три карточки (1/2/3 очка; 1:00 / 1:30 / 2:00). Таймер **не идёт**, пока слово не выбрано.
- «Заменить все слова»: все три слова меняются, счёт команды −1 (в т.ч. уходит ниже 0), штраф не повторяется после перезагрузки страницы.
- Тик слышен каждую секунду, в последние 10 с — выше и громче; по окончании времени — сигнал `timeout` и переход на итог раунда с «Время вышло».
- «Угадали» → +очки сложности слова; «Сдаёмся» и таймаут → 0.
- Команда достигла цели в конце своего раунда → экран победы с таблицей счёта.
- Слова не повторяются, пока есть невиданные в своей сложности; после показа всех слов сложности пул этой сложности (и только он) сбрасывается. Проверить, временно уменьшив пул до 3–4 слов.
- F5 в каждой фазе (особенно `choose_word` и `playing`): слова, выбранное слово и оставшееся время восстанавливаются.
- Не проверено вживую в браузере: в вебе пройдены только `tsc` и `eslint`.
