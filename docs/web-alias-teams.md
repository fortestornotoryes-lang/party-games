# Alias: выбор команд и составов (веб) — для переноса в React Native

> Дата: 2026-10-18. Изменения сделаны **только в вебе** (`src/`). В `mobile-app/` ничего не менялось — этот файл описывает, что и куда переносить.

## Проблема

В Alias игроков молча делили на 2 команды («Красные»/«Синие»): состав нигде не показывался, число команд поменять нельзя, на экране хода было видно только название команды — непонятно, кому передавать телефон.

## Что стало

1. **Новая фаза `Setup`** (перед первым `Start`): выбор числа команд (2…4), состав каждой команды, кнопка «Перемешать», ручная правка — тап по игроку переносит его в **следующую по кругу** команду. Кнопка «К ИГРЕ» неактивна, пока в какой-то команде меньше 2 игроков.
2. **Экран хода (`Start`)** показывает название команды, **объясняющего** («Объясняет: имя») и угадывающих списком. Объясняющий меняется по очереди внутри команды.
3. **До 4 команд**: красные, синие, зелёные, жёлтые. Победа/конфетти/кнопка на экране победы окрашены в цвет победившей команды.

## Правила

- Макс. команд = `clamp(floor(players / 2), 2, 4)` (`getMaxTeams`): 4–5 игроков → 2 команды, 6–7 → 3, 8+ → 4. Селектор показывает только допустимые значения.
- Смена числа команд и «Перемешать» делают **новую случайную раздачу** (круговая по перемешанному списку — размеры отличаются максимум на 1). Ручные правки при этом сбрасываются.
- Ручной перенос может оставить в команде меньше 2 игроков (или ни одного); это ловится валидацией (`isTeamsValid`), счётчик команды краснеет, подсказка меняется на «В каждой команде минимум 2 игрока», старт заблокирован.
- Объясняющий = `team.players[turnsPlayed % players.length]`; `turnsPlayed` увеличивается у команды в `finishRound`. Порядок игроков в команде = порядок на экране настройки.
- Условия победы не менялись: первая команда, набравшая `WIN_SCORE` (30) в конце своего раунда. При >2 командах порядок ходов — по кругу `(i + 1) % teams.length`.
- Начальная фаза теперь `Setup`. Старые сохранённые сессии (фаза `start`, 2 команды без `turnsPlayed`) продолжают работать: `turnsPlayed ?? 0`.

## Заметки по RN

- **Цвета.** Классы Tailwind/NativeWind нельзя собирать динамически (`text-premium-${c}`) — оставить карту `TEAM_STYLES` с литеральными классами. `premium-green` / `premium-yellow` уже есть в `colors.ts`. Кнопки: у `PrimaryButton` нет жёлтого варианта — для жёлтой команды используется `white`, зелёной — `emerald`.
- **Чипы игроков** — это `Pressable` с `min-height 44` (цель нажатия, см. W-08 в `web-ux-fixes.md`), `max-width: 100%`, длинное имя должно переноситься (не `numberOfLines={1}`, см. W-03). Список чипов — `flexDirection: 'row', flexWrap: 'wrap', gap: 8`.
- **Экран `Setup`** может не поместиться на низких экранах (4 команды × несколько строк чипов) — делать контент в `ScrollView`, кнопки «Перемешать»/«К игре» держать внизу контента, а не в `position: absolute`.
- **Имена в списке угадывающих** (`guessers.join(', ')`) и имя объясняющего — длинные имена должны переноситься/ужиматься (в вебе `wrap-anywhere`; в RN — `FitText`-аналог из W-01 для объясняющего, обычный `Text` с переносом для списка).
- **Перемешать** — `feedbackService.vibrate`/звук идут из `PrimaryButton`; на чипах отдельной обратной связи в вебе нет.
- Блюр `GlassCard` не вкладывать друг в друга (см. `mobile-app/CLAUDE.md`): карточка команды на `Setup` — обычный `View` с полупрозрачным фоном и рамкой, не `GlassCard`.

## Проверка после переноса

- 4 игрока: селектор показывает только «2»; 6 → «2, 3»; 8+ → «2, 3, 4».
- Перенос игрока вручную до команды из 1 человека → старт заблокирован, подсказка красная/заменена.
- 3 команды: ходы идут красные → синие → зелёные → красные; у каждой команды объясняющий меняется только после её собственного раунда.
- Перезагрузка посреди раунда восстанавливает команды, `turnsPlayed` и фазу (поля сессии: `teams`, `phase`, `currentTeamIdx`).
- Победа жёлтой команды: жёлтые конфетти и кнопка выхода (`white`).
- Длинные имена («Достопримечательность», «Wolfeschlegelsteinhausen») на 360 px в чипах, у объясняющего и в списке угадывающих.
- Не проверено вживую в браузере: в вебе пройдены только `tsc` и `eslint`; визуальную проверку Setup/Start на 360 px стоит сделать перед переносом.
