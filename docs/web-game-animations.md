# Анимации Alias, Крокодила, «Двух правд» и «Кто из нас» (веб, 2026-10-18)

Пока только веб. Для RN (`mobile-app/`, moti + reanimated) — чеклист ниже; помнить про грабли RN в `.claude/memory/gotchas.md` (`transition.type` под `exitBeforeEnter`, `perspective` для 3D на Android).

## Общее (веб: `shared/theme/motion.ts`, `shared/components/*`)

- Пресеты пружин и вариантов: `SPRING`, `PHASE_VARIANTS` (фаза всплывает снизу + каскад детей), `STAGGER_ITEM`, `CARD_DEAL_VARIANTS` (3D-раздача), `SHAKE_X`.
- `RingTimer` — кольцо + цифры, перелистывающиеся каждую секунду; в последние секунды цифры «бьются», вокруг пульсирует красный ореол. `UrgencyVignette` — красная виньетка по краям.
- `AnimatedNumber` — прокрутка счёта. `VictoryHero` — кубок падает с отскоком, вращающиеся лучи, искры, «впечатанный» заголовок. `FlipCard` — переворот рубашка → лицо с задержкой.
- `LeaderboardList animated` — строки снизу вверх (победитель последним), очки от нуля. `FinalStandings` — финал игры на очки (корона + таблица).
- Настройка «Визуальные эффекты» = `MotionConfig reducedMotion="always"` (в RN — аналог через проверку настройки в общих анимационных компонентах).

## По играм

- **Alias**: свайп карточки слова (вправо — угадано, влево — пропуск; порог `SWIPE_OFFSET`/`SWIPE_VELOCITY` в constants), карточка наклоняется, проявляются штампы, улетает в сторону ответа (и при нажатии кнопок); колода позади; вспышка цвета ответа; всплывающие «+1/−1» над счётом. Setup: игроки перелетают между командами (`layoutId`), подсветка выбранного числа команд переезжает, иконка «Перемешать» крутится. Start: раздача карточки команды, блик, полосы прогресса до победы. RoundEnd: счёт прокручивается от нуля, волны.
- **Крокодил**: Setup/Start — как Alias. Выбор слова: карточки раздаются с 3D-переворотом, при замене переворачиваются заново, «−1» всплывает над кнопкой; выбранная карточка вспыхивает, остальные гаснут (пауза `PICK_DELAY_MS`). Игра: карточка слова переворачивается с рубашки, парит; RingTimer + виньетка. RoundEnd: угадано — конфетти (`GUESSED_CONFETTI`), волны, прокрутка очков; неудача — тряска «0».
- **Две правды**: фазы вынесены в `phases/`. Writing — красная плашка «Ложь» перелетает между карточками, у отмеченной — красное свечение, кнопка «Показать всем» пульсирует, когда всё готово. Vote — выбор с подсветкой. Reveal — правды переворачиваются по очереди, ложь последней после паузы (`REVEAL_TIMING`, `getRevealDelays` в helpers) с красной вспышкой, тряской, звуком и вибрацией; затем выезжают итоги голосования. Finish — `FinalStandings` + конфетти.
- **Кто из нас**: фазы в `phases/`. Вопрос — точки раундов, карточка раздаётся, текст проявляется по словам из размытия. Vote — плитки «выпрыгивают» каскадом, выбор с подсветкой. Result — полосы голосов растут по очереди (`RESULT_TIMING`), лидер с короной и бликом, заголовок лидеров «впечатывается». Finish — `FinalStandings` + конфетти.
