## МЕМО-РИСК — src/games/MemoRiskGame/ (обновлено 2026-06-11, 2-я итерация правил)

**GameKey:** `MemoRisk = 'memo_risk'` · **minPlayers:** 2 (`'2+'`) · **Тема:** `pink` · **Иконка:** `Shapes` · **i18n NS:** `MEMO_RISK` · **backgroundImage:** memoryImage2.png

### Правила (уточнены пользователем — не менять без запроса)
- **Фигуры раунда ОБЩИЕ для всех игроков** (персист-поле `round: RoundShapes | null`), НЕ пере-разыгрываются на каждом ходу. Меняются только: игрок забрал карты (tookCards), провал (выросла эскалация), фигура полностью выбыла с поля (`isRoundValid`). Показываются и на PassPhase (`ShapeBadges`).
- **Доска общая и стабильная**: карты не двигаются и не меняются; заменяются из колоды только забранные слоты; нейтральные/опасные переворачиваются рубашкой вверх НА СВОЁМ месте.
- **Целевая фигура** → очки по редкости, карта забирается, ход продолжается. Забрать можно ТОЛЬКО разрешённые фигуры (и супер-карту).
- **Нейтральная фигура** → 0 очков, ход ПРОДОЛЖАЕТСЯ (не завершает!), карта остаётся открытой до конца хода, потом переворачивается обратно.
- **Опасная фигура** → очки хода сгорают, ход передаётся АВТОМАТИЧЕСКИ через `BUSTED_PASS_DELAY_MS` (2с), без кнопки.
- **Банк** в любой момент (кнопка ЗАБРАТЬ N, disabled при 0).
- **Колода 100 карт** (`DECK_SIZE`): поле раздаётся из неё, забранные слоты пополняются при передаче хода (`endOfTurnCleanup`); колода кончилась → слоты пустеют (null). Счётчик колоды на экране (Pass и Playing).
- **Редкости** (`MemoRarity` + `RARITY_META`): common +1 (вес 50, белая рамка), uncommon +5 (27, зелёная), rare +10 (15, синяя/sky), epic +20 (8, фиолетовая). Ценность и рамка видны на лице карты («+N»).
- **Супер-карты** — 3 шт. в колоде, ×2 к очкам хода при банке (`SUPER_MULTIPLIER`), жёлтая рамка + Zap «×2».
- **Эскалация**: после провала `escalation+1` → больше целевых И опасных фигур; кламп в `pickRoundShapes`.
- **Конец партии**: на поле <2 видов фигур (`canStartRound` после cleanup) → GameOver.
- Режимы: classic / timed (20/25/30с по сложности, по таймауту очки банкуются) / limited (4/5/6 открытий, КАЖДОЕ открытие тратит попытку, включая нейтральные).

### Архитектура
- Карты — ЕДИНОЕ персист-поле `cards: CardsState {board: (MemoCard|null)[], deck: MemoCard[]}` (один lazy-инициализатор `createGame(cfg)` — нельзя было разнести board/deck по двум usePersistedState).
- `MemoCard.id` — уникальный id карты в колоде; React key = card.id ⇒ карта-замена в слоте ремоунтится без флип-анимации (иначе лицо новой карты мелькало бы при перевороте). `onFlip(slot)` — по индексу слота.
- `endTurn(result, points, doubled)` принимает значения явно (нельзя читать state после setState в том же тике).
- Авто-передача при Busted: `useEffect` на `outcome === Busted && phase === Playing` → `setTimeout(handleNextTurn, 2000)`; `handleNextTurn` обёрнут в useCallback.
- `TurnOutcome`: Banked / Busted / Timeout / OutOfFlips (Missed удалён — нейтральная не завершает ход).
- Таймер: `useTimer` + `usePersistedTimer`, авто-пауза эффектом при outcome ≠ null, guard в handleTimeUp.
- `gridSize = Math.round(Math.sqrt(board.length))` — не из cfg.

### Интеграция
- Sublabel сложности в UniversalGameSettings: `4×4 · 4 фиг.`.
- Время/лимит открытий — из difficulty-конфига (`MEMO_RISK_DIFFICULTY_CONFIG`), не из настроек таймера.
